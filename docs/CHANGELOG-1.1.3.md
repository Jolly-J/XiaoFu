# 1.1.3 · Compose 预测式返回修正

保留 Kotlin / Compose，不迁移 Flutter。依据用户指南中 PredictiveBackPageTransitionsBuilder 所对应的悬浮页面机制，修正既有应用内返回。

- 用同一组件管理进入、手势预览、取消回弹、确认退场和按钮返回，移除外层 AnimatedVisibility 的重复退出动画。
- 页面按手势进度缩小，保留圆角与边距，左右边缘对称，并根据手指的纵向位移调整卡片位置。
- 取消时恢复原页；确认后从当前预览位置连续淡出，动画结束才移除页面。
- 转写页保留退出所需内容，避免松手后立即卸载而闪切。
- 首页不注册启用的返回拦截，退出到桌面由系统处理。窗口背景与系统栏使用透明配置。
- 键盘和弹窗保留系统优先级；未改动转写或后台任务。

完整过程录屏、取消前后像素对比、手势/键盘路径和单元测试见 verification-1.1.3/RESULTS.md。

# 1.1.0 · 界面重做与后台并发转写

- 移除底部三栏、大型说明卡片和常驻宣传/提示文案，改用文件导入工作区、格式选择和提取按钮，历史与设置收进侧栏。
- 黑白灰浅/深色主题。操作优先使用图标并保留无障碍名称；必要上传与费用说明在开始时出现。
- 参照用户提供的客户端截图与 Surface 研究，使用大圆角细边分组、组内分隔线和圆形返回按钮；保留音频工具流程，不采用聊天输入框布局。
- 预测式返回跟随左右边缘手势缩放位移，露出上页，取消手势回弹；根页返回交由系统。
- 切片独立异步处理，最多 3 路并发。所有分片成功后按原顺序交付全文；失败段可重试，成功段不重复上传。
- 前台服务支持后台转写，常驻进度通知可取消和回到任务；完成后移除常驻状态。
- 按需请求通知权限，增加系统后台/通知设置入口；使用标准通知请求实时活动提升，不使用悬浮窗或厂商私有字段。
- 进程中断可手动续传成功缓存以外的段；不自动重传未获确认的付费请求。
- 保留本地编解码引擎、加密 Key 存储、上传确认及原有音频历史。

验证和限制见根目录 TEST_REPORT.md。测试 APK 与旧版报告的签名不同，正式覆盖升级需要原签名密钥。

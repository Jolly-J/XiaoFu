# 1.0.2 更新

- 修复合法负音频时间戳（包括-1微秒）被误当音轨结束，导致M4A/WAV报无音频数据；保留AAC完整包并统一输出时间基准。
- 对系统确认不可seek的文件提供器管道，安全暂存到本地私有缓存后处理；普通文件仍直接读取。支持取消、可靠管道错误、offset/length、提前EOF检查与清理。
- 新增设置/失败卡片“复制诊断信息”，只含白名单技术元数据，不含API Key、媒体内容、文件名、URI或路径。
- 进程启动清理本应用遗留的未完成来源暂存文件，不删除成功导出或其他缓存文件。
- 保持主页仅转音频、历史可选转文字、设置主题/Key的三页结构与旧版签名。

验证：API35最终37/37通过；API28最终36/37通过，唯一失败是该旧平台系统明确不支持MP3音轨置于MP4/3GPP。两平台均完成16:12、44.1kHz双声道的M4A/WAV全长度回归。详细记录及界面验证以TEST_REPORT为准。

限制：未获得用户原始视频，未在其手机测试；未调用真实MiniMax。不能据模拟器矩阵保证所有格式、容器或厂商编解码器兼容。
